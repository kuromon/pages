About This Site

This site is a controlled fixture for search indexing experiments. It is deployed as a plain static site on Cloudflare Pages: no server-side rendering, no client-side routing, no JavaScript that the crawler has to execute before it can read the content.

Why the design is deliberately minimal

Every added layer is a place where crawling can differ from what a human sees. By serving static HTML over a normal CDN with no build step, the page a search engine receives is the same bytes a browser receives. That removes rendering as a variable when a page behaves unexpectedly in the index.

Verifying that a page is indexed

Use the URL Inspection tool in Google Search Console. Enter the exact URL and read the reported status. The useful outcomes are:

  • URL is on Google — the page is indexed and can appear in results.
  • URL is not on Google — the crawler may know the URL but has not indexed it. Sub-reasons include "Discovered — currently not indexed" and "Crawled — currently not indexed".
  • Excluded by noindex tag — a directive is actively blocking indexing; fix the tag, then request a re-crawl.

Both of the "currently not indexed" states are normal for a new or low-signal hostname. They usually mean the crawler has queued the page but has not judged it worth indexing yet, not that something is broken.

Requesting a fresh crawl

After deploying a change, use Request Indexing in the URL Inspection tool. This queues a recrawl of that single URL. It does not guarantee indexing and it is rate-limited, so it is worth reserving for changes that actually alter the page's content or metadata.

Supporting files

  • sitemap.xml — the URL list submitted in Search Console.
  • robots.txt — crawl permissions and sitemap reference.

Google Search Indexing Test Page

This is the home page of the Kumo Index Test site. It exists for one purpose: to observe how a search engine discovers a page, fetches it, and decides whether to add it to its index. The site is intentionally small and static so that every signal a crawler reads is visible and easy to reason about.

What this site contains

  • A home page and an about page, linked to each other with ordinary HTML anchors.
  • A sitemap listing every public URL on the site.
  • A robots.txt file that allows crawling and points to the sitemap.
  • Canonical URLs and schema.org structured data on each page.

Why a separate test site helps

Indexing a brand new hostname is not instant. A crawler has to be told the site exists, has to reach the server, and has to find content worth keeping. Testing that process on a throwaway hostname means you can tell whether a delay comes from the page itself or from the search engine's own discovery schedule.

How to verify indexing

Searching for your own site is an unreliable check: rankings fluctuate and results are personalised. The dependable method is the URL Inspection tool in Google Search Console, which reports the crawler's last fetch, the indexed version of the page, and any excluded status for that exact URL.
